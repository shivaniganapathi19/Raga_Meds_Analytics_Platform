# Raga Meds Analytics Platform

## Project Overview

The Raga Meds Analytics Platform is an end-to-end healthcare retail analytics project developed using SQL and Power BI. The project analyzes medicine sales, customer purchasing behavior, inventory management, supplier performance, and purchase trends to support business decision-making.

The database is designed to simulate the operations of a medical retail store and provides meaningful business insights through advanced SQL queries and interactive Power BI dashboards.

---

## Project Objectives

- Analyze sales performance and revenue trends.
- Measure customer lifetime value and purchasing behavior.
- Monitor inventory levels and medicine availability.
- Evaluate supplier performance and purchase costs.
- Track profit margins and business KPIs.
- Build an interactive business dashboard using Power BI.
